# ambrs-binder

Binder surrogate for the [AMBRS](https://github.com/AMBRS-project/ambrs) repo.

Point Binder at this repo instead of the main one to avoid downloading the full 1.5 GB git history. The Dockerfile performs a shallow clone of the `main` branch.
